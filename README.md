🚀 Excited to share my latest AI project: **NER Intelligence Studio – Named Entity Recognition System**!

As part of my AI training journey at Instant, I developed an end-to-end Named Entity Recognition system using the CoNLL-2003 dataset.

Throughout this project, I implemented and compared multiple architectures:

🔹 LSTM  
🔹 BiLSTM  
🔹 BiLSTM + CRF  
🔹 BiLSTM + GloVe + Character CNN  
🔹 Fine-tuned BERT using Hugging Face Transformers

📊 **Results:**

The fine-tuned BERT model achieved:
- Precision: 90.96%
- Recall: 91.85%
- F1-score: **91.40% on the test set**

✨ **Project Features:**
- Named Entity Recognition for Persons, Organizations, Locations, and Miscellaneous entities.
- Character-level features and pre-trained GloVe embeddings.
- Comparison between deep learning and transformer-based models.
- Color-coded entity visualization.
- Dataset Explorer to compare actual labels with model predictions.
- Flask REST API for predictions.
- Interactive Gradio interface.

🛠️ **Technologies:** Python, PyTorch, Hugging Face, GloVe, Flask, Gradio, and Google Colab.

This project helped me gain practical experience in NLP, sequence labeling, model evaluation, and deploying AI applications.
